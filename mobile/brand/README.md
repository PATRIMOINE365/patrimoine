# Brand masters

Copied verbatim from the Patrimoine 365 Brand Package v1.1, `02-Logo/svg/`,
which lives outside this repository. The SVGs are the masters there and here;
every PNG in the Xcode asset catalogue is generated from them by
`scripts/build-icons.mjs`. Do not redraw them.

Per the brand README: the app icon and avatar come from the app-tile forms,
and on a dark ground the pillars are `#FFFFFF` with `#39D6A3` ledger bars.
